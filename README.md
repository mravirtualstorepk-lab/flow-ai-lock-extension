# Flow AI Lock Extension

A Chrome Extension that allows access only to Google Flow AI.

## Features

- 🔒 Admin Login
- 🔒 SHA-256 Password Hash
- 🔒 Session Timeout
- 🔒 Flow AI Only
- 🔒 Website Blocking
- 🔒 Access Denied Page

## Installation

1. Download the project.
2. Open Google Chrome.
3. Go to:

chrome://extensions

4. Enable Developer Mode.
5. Click **Load Unpacked**.
6. Select the project folder.

## Default Flow URL

https://labs.google/fx/tools/flow
